💡 Production Engineering Analysis

Pessimistic (FOR UPDATE): Optimal for high-demand flash sales; locks rows deterministically on disk pages with zero transaction retries.

OCC Versioning: Optimal for read-heavy catalogs with low write conflicts; avoids lock waits but cascades aborts on hot keys.

Advisory Locks: 64-bit application mutexes inside PostgreSQL memory; completely bypasses disk tuple write-locks.
